Design Patterns and SOLID in Java

A pattern is a named cure for a specific pain. If you cannot name the pain, you do not yet need the pattern.

Plain Java 21, no frameworks. Every pattern is taught pain first, built as a frozen kata, and applied to the evolving Smart Home Hub wherever it genuinely fits. The course gives equal weight to when not to use each one.

Each card is one page. Done cards open the lesson; next marks where to continue; planned cards are written as the course reaches them.
